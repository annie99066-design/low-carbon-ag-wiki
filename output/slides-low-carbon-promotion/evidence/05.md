# 第 05 頁：專案端困境──錢不夠分

| 欄位 | 內容 |
|---|---|
| 論點 | 交易成本中，年度固定成本最能決定專案成敗 |
| 數字與單位 | 買方年度固定成本（專案管理、監測）對最小可行規模的彈性：0.89（印尼）、0.95（澳洲），排名第一 |
| 來源 | Cacho2013，p. 239，Table 5 |
| 情境 | 印尼小農農林複合、澳洲家庭農場造林；CER 價格 20 USD/t CO₂e |
| 限制 | 示範性模擬，參數來自二手資料 |
| 原文依據 | wiki/papers/Cacho2013.md「關鍵數據與結果」第 4 點 |

| 欄位 | 內容 |
|---|---|
| 論點 | 行政與 MRV 吃掉一大塊收入 |
| 數字與單位 | 農民拿到碳信用收入的 60–80%，其餘 20–40% 用於 NGO 行政與 MRV |
| 來源 | Shin2026，p. 2 |
| 情境 | 烏干達現行碳專案（質性訪談） |
| 限制 | 來自 NGO 受訪者的說法，不是帳目資料 |
| 原文依據 | wiki/papers/Shin2026.md「關鍵數據與結果」第 2 點 |

| 欄位 | 內容 |
|---|---|
| 論點 | 農民要求的補償遠高於實際收入 |
| 數字與單位 | 農民要求約 54 USD/ha/年，實拿約 8 USD/ha/年 |
| 來源 | Shin2026，p. 2（8 USD）、p. 4（54 USD） |
| 情境 | 54：Otuke 未接觸碳專案的小農問卷；8：已有碳專案地區的質性資料 |
| 限制 | **54 為陳述性問卷估計值，對起始出價敏感**；兩個數字來自不同地區 |
| 原文依據 | wiki/papers/Shin2026.md「關鍵數據與結果」第 1–2 點 |

**頁尾術語**：交易成本＝把減碳成果變成可交易商品的成本（搜尋、核准、管理、監測、保險）；MRV＝量測、報告、查證（measurement, reporting, verification）。

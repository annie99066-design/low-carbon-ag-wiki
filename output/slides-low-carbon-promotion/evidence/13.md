# 第 13 頁：農民端策略──合約設計

| 欄位 | 內容 |
|---|---|
| 論點 | 混合式付款兼顧農民的低風險與可驗證的成果 |
| 數字與單位 | 三種機制：成果導向（MRV 高、風險高）、行動導向（MRV 低、成果不確定）、混合式（先預付、再依成果追加）；例：肯亞 TIST 每棵樹預付 0.018 USD，事後再分碳信用 |
| 來源 | Raina2024，p. 9–10，Table 3、Fig. 5 |
| 情境 | 全球約 40 個案例 |
| 限制 | 系統性圖譜只做描述，沒有比較各機制的效率 |
| 原文依據 | wiki/papers/Raina2024.md「關鍵數據與結果」第 1 點、「結論」 |

| 欄位 | 內容 |
|---|---|
| 論點 | 碳權租賃能降低雙方風險，但需要更大規模 |
| 數字與單位 | 碳價低時，租賃型合約所需的最小規模最多可達購買型的 2 倍；租賃型合約在農民退出時不需訴訟追回款項 |
| 來源 | Cacho2013，p. 240–242 |
| 情境 | 印尼與澳洲示範性模擬 |
| 限制 | 二手參數；作者指出當時市場上尚無實際的碳租賃合約 |
| 原文依據 | wiki/papers/Cacho2013.md「關鍵數據與結果」第 3 點、「結論」 |

**頁尾術語**：成果導向（result-based）＝依實測減碳量付錢；行動導向（action-based）＝依做了哪些措施付錢。
